## Обо мне

Разрабатываю ИИ-сервисы и инструменты для автоматизации. Сейчас больше всего работаю с технической поддержкой, базами знаний и обработкой документов. Отдельное направление — компьютерное зрение и измерение физических объектов по камере.

Работаю ведущим инженером по разработке интеллектуальных систем в ООО «Техавтоматика».

Обычно веду проект сам: разбираюсь в задаче, проектирую систему, пишу код, проверяю результат и занимаюсь запуском. Беру коммерческие задачи по автоматизации с ИИ. Начинаю с разбора процесса: что занимает время, какие данные есть и где автоматизация будет полезна.

Основал и развиваю **dev-decisions**, собственную инженерную практику в прикладном ИИ и автоматизации бизнеса. Совмещаю ведение бизнеса с разработкой: нахожу заказчиков, разбираю требования, оцениваю объём и стоимость работ, согласовываю коммерческие условия и веду проекты. При этом сам проектирую архитектуру и пишу код.

Для отдельных задач привлекаю разработчиков из своего пула; также работал с приглашёнными UI/UX-дизайнерами. Формулирую задачи, координирую работу и проверяю результат.

## Чем занимаюсь

- **ИИ-агенты.** Память диалога, вызов инструментов, работа с текстом, изображениями и голосом. Сохранение фактов, учёт исправлений пользователя и выполненных проверок.
- **Базы знаний и RAG.** Извлечение текста, таблиц и иллюстраций из документации, OCR, поиск по смыслу и ключевым словам, ранжирование результатов. Сохранение ссылок на источники и их версии.
- **Backend.** Сервисы на Python и Go, API, фоновые задачи, хранение состояния. Обработка повторных запросов и восстановление работы после обрыва связи.
- **Проверка качества.** Сценарии из нескольких реплик, повторное воспроизведение диалогов, сравнение версий, разбор ошибок, замеры задержек и стоимости.
- **Компьютерное зрение и измерения.** Облака точек, восстановление геометрии, оценка объёма, обработка показаний датчиков и проверка качества данных.

## Проекты

Большая часть текущей работы находится в закрытых репозиториях. Ниже — краткие описания задач.

### Станки для внутрисхемной прошивки

ПО для настольного и портального станков, автоматизирующих прошивку микроконтроллеров на платах. Моя работа включает интерфейс оператора, взаимодействие с оборудованием, сценарии программирования и диагностики. Здесь разработка приложений на Python соединяется с интеграцией промышленного оборудования.

### Управление устройствами и телеметрия

Backend-система для работы с устройствами, пользователями и телеметрией: REST API, авторизация, сбор данных, журналирование событий и уведомления через Telegram. Стек: FastAPI, SQLAlchemy, asyncio, PostgreSQL и Docker.

### Видеосистема инспекционного робота

Многокамерная трансляция и запись видео с интерфейсом оператора. Работал над параллельной обработкой видеопотоков и управлением трансляцией на Python, GStreamer, OpenCV и PyQt.

### ИИ-техподдержка

Ассистент для поддержки промышленного оборудования. Есть реализация на Python, развиваю новую версию на Go. Работаю над поиском по технической документации, памятью диалога, обработкой изображений и голосовых сообщений, проверкой ответов и передачей обращения специалисту.

Много внимания уделяю тому, как продолжается диалог: какие сведения уже известны, что пользователь проверил, что изменилось после его уточнения и какой вопрос нужно задать дальше. Качество проверяю на целых диалогах с сохранением ответов, источников и времени работы.

### Подготовка технической базы знаний

Обработка документации на нескольких языках: тексты, таблицы, изображения, характеристики оборудования и пошаговые инструкции. Сохраняю версии исходных материалов, проверяю дубли и ошибки извлечения.

Здесь важна привязка к конкретному оборудованию: упоминание двух устройств в одном документе не означает, что у них одинаковые характеристики. Это учитываю при подготовке данных и поиске.

### Генерация документов

Веб-приложение для работы с шаблонами и выпуска документов. Версии шаблонов, формы ввода, заполнение из файлов и с помощью LLM. Документация на изделия публикуется по версиям, у каждой есть ссылка и QR-код. Backend на Python, интерфейс на React и TypeScript.

### Тарировка баков по камере — в разработке

Android-приложение для восстановления геометрии бака и расчёта таблицы «уровень — объём». Использую ARCore, данные глубины и облака точек. Работаю над объединением данных с разных ракурсов, выделением объекта, подгонкой геометрических моделей и восстановлением незавершённых измерений.

Записанные сессии можно воспроизводить повторно, чтобы проверять изменения алгоритмов на одних и тех же данных.

### Среда для кодинг-агента — прототип

Экспериментальный проект на Go: агент работает с репозиторием через инструменты с заданными правами. Есть память, журнал действий, согласование изменений и откат. На этом проекте разбираюсь, как организовать работу агента так, чтобы можно было проверить его действия и результат.

## Как работаю

Стараюсь заранее определить, как будем проверять результат. Для ассистента это диалоги и источники ответов, для измерительного приложения — записи сканирования и повторяемые расчёты.

При разборе ошибок смотрю, на каком этапе возникла проблема: в исходных данных, поиске, состоянии, модели или коде. По возможности упрощаю архитектуру. Новые компоненты добавляю под конкретную задачу.
